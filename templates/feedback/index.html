DBMS Viva Note: MongoDB Aggregation Pipeline ($group, $avg)

Average trainer ratings are calculated using a MongoDB aggregation pipeline: db.feedback.aggregate([{"$group": {"_id": "$trainer_id", "avgRating": {"$avg": "$rating"}, "totalReviews": {"$sum": 1}}}]). The resulting aggregated ratings are then joined in-memory with the SQL trainers table by matching _id to trainer_id.
