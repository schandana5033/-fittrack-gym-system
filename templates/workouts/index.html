DBMS Viva Note: Embedded Arrays in NoSQL

Workout sessions are stored in MongoDB's workout_logs collection. Notice the embedded exercises array inside each document: {"member_id": 1, "date": "2026-03-01", "exercises": [{"name": "Bench Press", "sets": 4, "reps": 10, "weight": 65}]}. In a purely relational database, this would require 2 tables (e.g. workout_sessions and workout_exercises) joined via foreign keys. MongoDB stores the entire session atomically in one document.
