DBMS Viva Note: Advanced SQL Joins, Group By & Hybrid Queries

This reporting module showcases key database querying concepts:
1. Multi-Table Relational JOIN: INNER/LEFT JOIN combining normalized entities (Members, Plans, Trainers).
2. Aggregation with GROUP BY: COUNT(m.member_id) and SUM(p.price) to calculate revenue per plan.
3. Polyglot Hybrid Reporting: Merging relational SQL metrics (assigned members, scheduled classes) with NoSQL MongoDB metrics (reviews and ratings).
